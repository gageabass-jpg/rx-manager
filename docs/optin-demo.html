Text reminder opt-in — demonstration

A recording of how a user consents to SMS medication refill reminders in the Rx Manager app. Text reminders are optional; the app works fully without them.

What the recording shows

  1. Opening the Rx Manager app and going to Settings.
  2. Tapping Enable text reminders, which opens the opt-in page.
  3. Entering a mobile number and checking the consent box, which is unchecked by default.
  4. The consent disclosure (recurring automated reminders, message frequency varies, msg & data rates may apply, Reply STOP to cancel / HELP for help).
  5. Submitting to enable reminders.
Live opt-in page: rxmanager.us/optin.html (no login required).
